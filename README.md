# DAW - Desarrollo de Aplicaciones Web

## Descripción del repositorio

Este repositorio contiene las actividades y prácticas realizadas durante el ciclo de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo es aprender programación, desarrollo web y control de versiones utilizando diferentes herramientas.

### Contenido del repositorio

En este repositorio podemos encontrar:

- Prácticas de HTML.
- Ejercicios de CSS.
- Actividades de JavaScript.
- Prácticas de Git y GitHub.

## Tecnologías utilizadas

Las tecnologías principales de este proyecto son:

- **HTML5**
- **CSS3**
- **JavaScript**
- **Git y GitHub**
